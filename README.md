# Yang Qian

Personal portfolio, built with Next.js 16 and Tailwind CSS v4.

Based on [chanhdai.com](https://github.com/ncdai/chanhdai.com) (MIT). Personal branding from that template has been replaced.

## Develop

```bash
pnpm install
pnpm dev
```

## Build

```bash
pnpm build
pnpm start
```

Set `NEXT_PUBLIC_APP_URL` to your live site URL before deploying.
